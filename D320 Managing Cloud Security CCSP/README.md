# D320 – Managing Cloud Security

Study notes and practice resources for **WGU D320 – Managing Cloud Security**, covering cloud security concepts related to the **ISC2 CCSP** certification.

## Study Notes

The uploaded 25-page notes are organized into six readable Markdown sections. Follow the order below for a complete read-through, or jump to a topic for review. The chapter numbers refer to the source document, not official exam domains.

| Section | Source chapters | Focus |
|---|---|---|
| [01 — Cloud Foundations](notes/01-Cloud-Foundations.md) | 1, 2 | Service models, deployment models, business requirements, risk |
| [02 — Cloud Data Security](notes/02-Cloud-Data-Security.md) | 3, 4 | Classification, lifecycle, storage, encryption, masking, IRM |
| [03 — Cloud Infrastructure and Responsibilities](notes/03-Cloud-Infrastructure-and-Responsibilities.md) | 5, 6 | Deployment risks, virtualization, networking, SOC reports |
| [04 — Cloud Application Security](notes/04-Cloud-Application-Security.md) | 7 | SDLC, IAM, federation, APIs, application protection and testing |
| [05 — Cloud Operations and Recovery](notes/05-Cloud-Operations-and-Recovery.md) | 8, 9 | Availability, clusters, monitoring, BC/DR, recovery, backups |
| [06 — Legal Compliance and Risk](notes/06-Legal-Compliance-and-Risk.md) | 10, 11 | Privacy, legal concepts, standards, evidence, risk, assurance |

Each file includes topic headings, a contents list, previous/next navigation, and original review questions with expandable answers. Miscellaneous topics from the source document are grouped into the relevant files.

**Source note:** The Markdown files reorganize the uploaded *Updated 25pg Doc - CCSP Notes.docx*. They preserve the original chapter material and are not a full technical or legal fact-check. Treat dated standards, legal summaries, and absolute claims as items to verify against current course materials. The existing PDF is retained separately; the two versions have not been verified as identical.
