# 🎓 WGU B.S. Cybersecurity & Information Assurance Notes

A collection of my study notes from the **B.S. Cybersecurity and Information Assurance (BSCIA)** program at **Western Governors University (WGU)**.

This repository contains notes from the courses and certification material I've completed throughout the degree. I use it as a central place to organize my studies and as a reference for cybersecurity concepts I've learned along the way.

---

## 📚 What's Included

Notes cover topics such as:

* 🔐 Cybersecurity fundamentals
* 🌐 Networking and network security
* 🔎 Security operations
* 🐛 Vulnerability management
* 🚨 Incident response
* ⚔️ Penetration testing
* ☁️ Cloud security
* 👤 Identity and access management
* 📋 Governance, risk, and compliance
* 🐧 Linux and scripting
* 🔒 Cryptography

Each course has its own folder containing the relevant notes and study material.

## 🏆 Certifications

The WGU BSCIA program includes several industry certifications. This repository contains study material for certifications such as:

* **CompTIA A+**
* **CompTIA Network+**
* **CompTIA Security+**
* **CompTIA CySA+**
* **CompTIA PenTest+**
* Other certifications included throughout the BSCIA program

Certification-heavy courses may have their notes organized according to the official exam objectives and domains.
