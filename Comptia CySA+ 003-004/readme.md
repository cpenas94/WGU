# CompTIA CySA+ (CS0-003) Study Notes

A comprehensive collection of my study notes for the **CompTIA Cybersecurity Analyst (CySA+) CS0-003** certification exam.

This repository organizes the CySA+ exam objectives by domain and topic, providing structured notes covering security operations, vulnerability management, incident response, threat intelligence, reporting, and other concepts required for the exam.

The goal is to provide a centralized reference for reviewing the major concepts, tools, techniques, and terminology covered by **CS0-003**.

---

## 📚 Exam Domains

The CompTIA CySA+ CS0-003 exam is divided into four primary domains:

| Domain  | Topic                        | Exam Weight |
| ------- | ---------------------------- | ----------: |
| **1.0** | Security Operations          |     **33%** |
| **2.0** | Vulnerability Management     |     **30%** |
| **3.0** | Incident Response Management |     **20%** |
| **4.0** | Reporting and Communication  |     **17%** |

---

## 🛡️ Domain 1 — Security Operations

Focuses on detecting, analyzing, and investigating security threats using security tools, logs, intelligence, and network data.

### Topics

* **1.1** System and Network Architecture Concepts
* **1.2** Indicators of Malicious Activity
* **1.3** Tools and Techniques for Determining Malicious Activity
* **1.4** Threat Intelligence and Threat Hunting
* **1.5** Efficiency and Process Improvement in Security Operations

**Key concepts include:**

SIEM • EDR • IDS/IPS • DNS • Network Traffic Analysis • Log Analysis • IoCs • Threat Intelligence • Threat Hunting • MITRE ATT&CK • Security Automation

## 🔍 Domain 2 — Vulnerability Management

Covers identifying, prioritizing, analyzing, and remediating vulnerabilities across systems and applications.

### Topics

* **2.1** Vulnerability Scanning Methods and Concepts
* **2.2** Vulnerability Assessment and Analysis
* **2.3** Vulnerability Prioritization
* **2.4** Vulnerability Response and Remediation

**Key concepts include:**

Vulnerability Scanning • CVE • CVSS • CWE • EPSS • Asset Criticality • Attack Surface • Credentialed Scans • False Positives • Patching • Compensating Controls • Risk Acceptance

## 🚨 Domain 3 — Incident Response Management

Covers the processes and techniques used to prepare for, detect, contain, eradicate, and recover from cybersecurity incidents.

### Topics

* **3.1** Attack Methodology Frameworks
* **3.2** Incident Response Activities
* **3.3** Preparation and Post-Incident Activities

**Key concepts include:**

Incident Response Lifecycle • Preparation • Detection • Analysis • Containment • Eradication • Recovery • Digital Forensics • Evidence Handling • Chain of Custody • MITRE ATT&CK • Cyber Kill Chain • Diamond Model

## 📊 Domain 4 — Reporting and Communication

Executive Reporting • Technical Reporting • Stakeholder Communication • Incident Reports • Root Cause Analysis • Lessons Learned • Metrics • KPIs • Escalation • Regulatory Requirements

## 🧠 How to Use These Notes

These notes are designed primarily for **exam review and reinforcement**.

A good study approach is to:

1. Review each domain individually.
2. Make sure you understand the terminology rather than only memorizing definitions.
3. Practice interpreting logs, alerts, and command output.
4. Learn how security tools are used in real-world scenarios.
5. Practice identifying the **best next action** during incident-response scenarios.
6. Use practice exams to identify weak domains.
7. Return to the corresponding notes for targeted review.

---

## 🎯 High-Priority CySA+ Skills

While studying, pay particular attention to your ability to:

* Analyze security logs
* Recognize indicators of compromise
* Interpret network traffic
* Identify malicious activity
* Prioritize vulnerabilities
* Interpret CVSS and vulnerability information
* Understand common attacks
* Choose appropriate incident-response actions
* Understand attack frameworks
* Interpret security-tool output
* Recommend remediation techniques
* Communicate findings to different audiences

CySA+ is heavily focused on **analysis and decision-making**, so knowing *why* an answer is correct is often more important than memorizing individual definitions.
